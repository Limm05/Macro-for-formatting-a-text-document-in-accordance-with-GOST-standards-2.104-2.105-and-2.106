# Генератор документов по ГОСТ для MS Word

Данный макрос создает скелет текстового документа в соответствии с ГОСТ Р 2.104-2023 («Основные надписи»), ГОСТ Р 2.105-2019 («Общие требования к текстовым документам») и ГОСТ Р 2.106-2019 («Текстовые документы»). 

Инструмент подходит для написания отчетов, пояснительных записок курсовых, ВКР, а также для работы в организациях.

---

## ⚙️ Способы установки макроса

### Способ 1: Прямая вставка кода (самый простой)
1. Откройте редактор Microsoft VBA (`Alt + F11`).
2. В верхнем меню выберите **Insert -> Module**.
3. В появившееся окно вставьте код макроса.
4. При необходимости отредактируйте код под свои задачи.

### Способ 2: Глобальный шаблон для всего Word
1. Скачайте готовый шаблон **`GOST.dotm`** и поместите его в папку автозагрузки Word. 
   > Рекомендуемый путь: `C:\Users\ИМЯ_ПОЛЬЗОВАТЕЛЯ\AppData\Roaming\Microsoft\Word\STARTUP`
2. Перейдите в **Параметры Word** -> **Надстройки**.
3. Если шаблон не добавился автоматически:
   * В поле **Управление** выберите пункт **Шаблоны** и нажмите **Перейти...**
   * Нажмите **Добавить...** и укажите путь к вашему файлу `GOST.dotm`.

---

## 🚀 Использование макроса

Независимо от выбранного способа установки, для запуска макроса выполните следующие действия:

1. Установите курсор в самом конце титульного листа документа.
2. Нажмите комбинацию клавиш `Alt + F8`.
3. В списке выберите макрос **`BuildGOSTDocument`** и нажмите **Выполнить**:

   ![Окно выбора макроса](https://github.com/user-attachments/assets/636b0b1e-7a15-4127-bf4a-ca740a596c11)

4. В появившихся диалоговых окнах выберите требуемые настройки и укажите текст для штампа рамки. 
   *(Если потребуется изменить текст в уже готовом файле, сделайте это двойным кликом по штампу).*

---

> [!CAUTION]
> **ВНИМАНИЕ!** При создании скелета документа **все содержимое после титульного листа удаляется**. 
> 
> * Не применяйте макрос на файлах с уже готовым важным текстом.
> * Запускайте макрос **только в новом чистом файле**, и только после этого приступайте к написанию текста.
