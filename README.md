# Macro-for-formatting-a-text-document-in-accordance-with-GOST-standards-2.104-2.105-and-2.106.
Макрос оформления текстового документа согласно ГОСТам 2.104, 2.105 и 2.106

Данный макрос создает скелет текстового документа в соответствии с ГОСТ Р 2.104-2023 Основные надписи, ГОСТ Р 2.105- 2019 Общие требования к текстовым документам и ГОСТ Р 2.106- 2019 Текстовые документы. Может быть использовано как для написания отчетов, пояснительных записок курсовых и ВКР, так и для пояснительных записок в организациях - ГОСТ все-таки.

Способы установки макроса:
  Первый способ самый простой и прямой. 
      Необходимо открыть Microsoft VBA (alt+F11) и вставить модуль (Insert -> Module). 
      В появившееся окно вставить код макроса.
      При необходимости переписать код под себя.
  Второй способ заключается в глобализации шаблона на весь Word.
      Скачать готовый шаблон GOST.dotm и вставить его в удобное место. Рекомендую следующий путь: C:\Users\ "NAME" \AppData\Roaming\Microsoft\Word\STARTUP
      Перейти в Параметры Word / Надстройки.
